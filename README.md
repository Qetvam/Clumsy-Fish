# Hate Game
"Игра, которая тебя ненавидит" на Pygame в рамках трехнедельного проекта ЮНИТ

## Как запустить:
### Вариант 1: Через консоль / терминал
1. Скачайте проект (зеленая кнопка Code -> Download ZIP) и распакуйте архив.
2. Откройте терминал в папке с игрой.
3. Установите зависимости командой: `pip install pygame`
4. Запустите игру командой: `python hate_game_main_menu.py`

### Вариант 2: Через PyCharm
1. На стартовом экране PyCharm нажмите **Open** (или в верхнем меню **File -> Open...**) и выберите распакованную папку проекта.
3. Откройте встроенный терминал
4. Установите библиотеку командой: `pip install pygame`
5. Запустите файл `hate_game_main_menu.py`
